Testing Your MQTT Server:
a)MQTT Client Tools:
You can use MQTT client tools like MQTT Explorer or MQTT.fx to connect to your MQTT server and publish/subscribe to topics.

b)Using mosquitto_pub and mosquitto_sub Commands:
These are command-line tools that come with Mosquitto. You can use them to test publishing and subscribing to topics.

i)Publish a message:
mosquitto_pub -h localhost -t test/topic -m "Hello MQTT"
This command publishes the message "Hello MQTT" to the topic test/topic on your local MQTT server.

ii)Subscribe to a topic:
mosquitto_sub -h localhost -t test/topic
This command subscribes to the topic test/topic on your local MQTT server and prints any messages received on that topic.

Using Docker:
If your Mosquitto broker is running inside a Docker container, you can use the docker exec command to run mosquitto_pub and mosquitto_sub inside the container. Replace <container_id_or_name> with your container's ID or name.
docker exec -it <container_id_or_name> mosquitto_pub -h localhost -t test/topic -m "Hello MQTT"
docker exec -it <container_id_or_name> mosquitto_sub -h localhost -t test/topic
These methods should help you test your MQTT server and verify that it's working as expected.
